1. Arithmetic Operators

Perform maths on numbers. Results are always a Number (except + with strings).

Operator Name Example Result
+Addition10 + 515

*Multiplication10 * 550
/Division10 / 52
%Remainder10 % 31
**Exponentiation2 ** 38
 
console.log(10 + 5);  // 15
console.log(10 % 3);  // 1  ← remainder of 10 ÷ 3
console.log(2 ** 3);  // 8  ← 2³

// Watch out — + with strings joins them:
console.log("5" + 5); // "55" ← not 10!

4. == vs === (Loose vs Strict Equality)

This is one of the most important distinctions in JavaScript. Always prefer ===.

== Loose equality

JavaScript converts types before comparing — can produce surprising results. 

5 == "5"   // true ⚠️
0 == false // true ⚠️

=== Strict equality ✅

Both value and type must match. No surprises. 

5 === "5"   // false ✅
0 === false // false ✅

5. Logical Operators

Combine or reverse conditions. Always return a Boolean.

&& AND

Both must be true

|| OR

At least one must be true

! NOT

Reverses a boolean

const age = 20;
const hasId = true;

// AND — both must be true
console.log(age >= 18 && hasId); // true

// OR — at least one must be true
const isAdmin = false;
const isOwner = true;
console.log(isAdmin || isOwner); // true

// NOT — reverses the value
console.log(!true);  // false
console.log(!false); // true

6. Ternary Operator

A compact if/else in one line: condition ? valueIfTrue : valueIfFalse 

// Instead of:
if (age >= 18) {
  status = "Adult";
} else {
  status = "Minor";
}

// You can write:
const status = age >= 18 ? "Adult" : "Minor";

7. Operator Precedence

JavaScript evaluates expressions in a specific order. Multiplication and division happen before addition and subtraction — just like in maths. Use parentheses to control the order. 

10 + 5 * 2    // → 10 + 10 → 20  (multiplication first)
(10 + 5) * 2  // → 15 * 2  → 30  (parentheses first)

let result  = 10 + 5 * 2;   // 20
let result2 = (10 + 5) * 2; // 30

8. Type Conversion

Convert values between types explicitly to avoid unexpected results.

Function Converts to Example Result
Number() Number Number("20") 20
String() String String(100) "100"
Boolean() Boolean Boolean(0) false 
// Falsy values — treated as false in a Boolean context:
Boolean(false);     // false
Boolean(0);         // false
Boolean("");        // false
Boolean(null);      // false
Boolean(undefined); // false
Boolean(NaN);       // false

// Everything else is truthy:
Boolean(1);         // true
Boolean("hello");   // true
Boolean([]);        // true (empty array!)
Boolean({});        // true (empty object!)
