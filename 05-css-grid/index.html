Each string in grid-template-areas is a row. Each word is a named area. Use grid-area on items to assign them.

5. grid-column & grid-row Spanning

Items can span multiple columns or rows using grid line numbers. 1 / 3 means from line 1 to line 3 (2 columns wide). 1 / -1 spans the entire row.

7. auto-fit + minmax — Responsive Without Media Queries

repeat(auto-fit, minmax(200px, 1fr)) — each column is at least 200px wide but grows to fill space. The browser automatically adds or removes columns as the window resizes. No media queries needed.
