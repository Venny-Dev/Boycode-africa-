JavaScript — Variables & Data Types

Open DevTools (F12) → Console to see all console.log() output.

1. let, const, and var

JavaScript has three keywords for declaring variables. Understanding when to use each is important.

Keyword Can Reassign? Era Advice
const No ES6 (Modern) Use by default
let Yes ES6 (Modern) Use when value changes
var Yes Pre-2015 Avoid in new code 
// const — value stays the same
const country = "Nigeria";

// let — value can change
let age = 20;
age = 21;  // ✅ fine
console.log(age); // 21

// const — reassignment throws an error
// country = "Ghana"; // ❌ TypeError

2. Variable Naming Rules

Variable names must follow these rules.

// ✅ Valid names
let firstName = "Victor";
let age = 20;
let _count = 0;
let $price = 100;

// ❌ Invalid names
// let 2name = "Victor";   → cannot start with a number
// let my name = "John";   → no spaces allowed
// let let = "test";       → reserved word

// JavaScript is case-sensitive
let firstName2 = "Victor";
let FirstName  = "John";   // different variable!

3. The Seven Core Data Types

JavaScript has seven data types beginners need to know.

String "Hello", 'Victor'
Number 20, 3.14, -100
Boolean true, false
Undefined declared, no value
Null intentionally empty
Object { key: value }
Array ["a", "b", "c"]

4. Strings & Template Literals

Strings store text. Template literals (backticks) let you embed variables directly.

const name = "Victor";
const age = 25;

// Old way — concatenation
console.log("Hello " + name + ", you are " + age + " years old.");

// Modern way — template literal
console.log(`Hello ${name}, you are ${age} years old.`);
// Output: Hello Victor, you are 25 years old.

// Expressions inside ${}
console.log(`10 + 5 = ${10 + 5}`);
// Output: 10 + 5 = 15

5. Objects

An object groups related data as key-value pairs.

const user = {

name: "Victor",

age: 25,

country: "Nigeria"

};

// Dot notation — most common
console.log(user.name);    // Victor
console.log(user.age);     // 25

// Bracket notation
console.log(user["country"]); // Nigeria

6. Arrays

Arrays store an ordered list of values. Each item has an index starting at 0.

"Apple"
index 0
"Mango"
index 1
"Orange"
index 2
const fruits = ["Apple", "Mango", "Orange"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango
console.log(fruits[2]); // Orange

console.log(fruits.length); // 3
