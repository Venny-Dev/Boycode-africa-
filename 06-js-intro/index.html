5. Adding JavaScript to HTML

Three approaches — from least to most preferred.

1. Inline (avoid for large scripts)

<button onclick="alert('Hello')">Click Me</button>

2. Internal (inside the HTML file)

<script>
  console.log("Hello World");
</script>

3. External ✅ Preferred

<!-- In your HTML file -->
<script src="script.js"></script>

/* In script.js */
console.log("Hello World");

Place the <script> tag at the bottom of <body> so the HTML is fully loaded before JavaScript runs.

6. Statements & Comments
